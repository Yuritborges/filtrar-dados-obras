# 📊 Filtrar Dados Obras

> Sistema Python para rastreamento de materiais utilizados em obras, desenvolvido para cliente real. Elimina a necessidade de abrir PDF por PDF para localizar itens específicos por obra.

---

## 📋 Sobre o Projeto

Desenvolvido para um setor de **compras e suprimentos**, onde era necessário verificar quais materiais e itens já haviam sido utilizados em determinadas obras. O processo manual envolvia abrir dezenas de PDFs e rolar página por página até encontrar o item desejado — um processo que tomava horas.

Este sistema automatiza completamente essa pesquisa.

---

## ✨ Funcionalidades

- ✅ Busca de itens por nome em múltiplos documentos
- ✅ Identificação de em quais obras o item foi utilizado
- ✅ Eliminação de busca manual em PDFs
- ✅ Resultados rápidos e precisos
- ✅ Interface simples para uso pelo setor de compras

## 💡 Problema Resolvido

```
CENÁRIO REAL — Setor de Compras/Suprimentos:

ANTES:
"Este item foi usado na Obra X?"
→ Abrir PDF da obra X
→ Ctrl+F ou rolar página por página
→ Repetir para cada obra
→ Tempo: 30-60 minutos por pesquisa

DEPOIS:
→ Digitar o nome do item
→ Sistema retorna todas as obras onde foi utilizado
→ Tempo: segundos
```
